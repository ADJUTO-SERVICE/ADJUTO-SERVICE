# ADJUTO SERVICE 配布・無料回収巡回管理マップ

ADJUTO SERVICEの配布・回収巡回をPCとiPhoneで管理する静的Webアプリです。

## 公開方法

GitHubのSettings → Pagesで「Deploy from a branch」、ブランチ「main」、フォルダ「/docs」を選んでSaveします。既存の会社HP用リポジトリとは別に管理します。

## iPhoneで使う

1. 公開された管理マップURLをSafariで開きます。
2. 「読込」から、iPhoneの「ファイル」に保存した初期ルートJSONまたはPCのバックアップを選びます。
3. Safariの共有メニュー → 「ホーム画面に追加」で、ホーム画面から開けます。

## 機能

- 配布日・協力者・チラシ種別、無料回収予定日（配布日の7日後を初期値）、巡回完了・完了日。
- 推定ルートの手動追加、点の移動・追加・削除、区間ごとの確認状態。
- スクリーンショット登録、地図部分の色線抽出、2地点による画像の位置合わせ。
- ブラウザ内保存、画像を含むJSONバックアップと読込、旧version 1のJSON読込。
- OpenStreetMapと国土地理院の地図切替、スマートフォン向け画面。

## データの扱い

この公開リポジトリには管理画面のプログラムだけを格納し、実際の配布ルート、スクリーンショット、協力者名、配布日を含めていません。初回は空の一覧です。管理記録は利用者のブラウザ内に保存され、GitHubへ自動送信・同期しません。

PCとiPhoneの記録は自動同期しません。「バックアップ」→別端末で「読込」で移します。ホーム画面版とSafari、別ブラウザ等では保存領域が分かれる場合があるため、移行時はバックアップしてください。背景地図には通信が必要です。

推定ルートはGPS記録ではありません。画像を基に作成した区間は道路と照合して確認してください。

## 技術

ビルド不要のHTML/CSS/JavaScript、Leaflet 1.9.4、IndexedDBを使用。相対パスによりGitHub PagesのプロジェクトURL配下で動作します。Leafletのライセンスはdocs/vendor/LICENSEに同梱しています。
